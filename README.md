## UI/UX 업데이트 (2026-11-06)

시각적 방향은 **작은 가게의 업무노트**입니다. 흰색·중성 회색 바탕에 짙은 녹색을 포인트로 쓰고, 문서·책갈피 심볼과 구분선이 있는 업무 요약을 사용합니다. 다크 모드는 중성 차콜 바탕입니다. 공통 색상·테마·모서리 값은 `src/styles/tokens.css`에서 변경합니다.

현재 UI 변경은 GitHub의 `codex/ui-design-handoff-20261106` 검토 브랜치로 제공합니다. Sites의 비공개 시연 배포와 GitHub main은 별도이며, 자동 동기화되지 않습니다.

- 상단 통합 검색: 메뉴·직원 별칭 검색, `Ctrl+K`, 방향키·Enter·Esc 지원. 역할별로 검색 대상을 제한합니다.
- 사장님 메뉴: 펼치기/아이콘만 보기, 왼쪽·오른쪽 배치, 모바일 전체 메뉴. 배치와 접힘 상태를 브라우저에 기억합니다.
- 라이트/다크 모드: 시스템 설정을 처음에 따르고, 상단 해·달 버튼으로 변경합니다. 선택은 `ai-labor-ui/theme`에 저장합니다.
- 로그인·회원가입: `/start`, `/start?mode=signup`. 입력 검사와 비밀번호 보기까지 제공하는 임시 UI이며 계정을 생성하거나 입력값을 저장·전송하지 않습니다.
- 사용 안내: 상단 `?`, 사이드 메뉴, 홈에서 4단계 애니메이션을 열 수 있습니다. 재생·정지·직접 이동을 지원하며 `prefers-reduced-motion`을 따릅니다.
- 홈: 할 일 필터, 실제 데이터로 계산한 인건비·직원 현황, 날짜를 선택할 수 있는 달력, 주간 근무와 알림을 배치했습니다.
- 기존 계산·데이터 스키마는 유지했습니다. UI 설정은 업무 데이터와 별도 키로 저장합니다.

확인: 66개 기존 테스트 통과, 1440px 데스크톱 및 375px 모바일에서 주요 화면과 검색·메뉴·테마·가입 시연·가이드를 확인했습니다. 인증·서버 저장·외부 연동은 계속 연결 전입니다.

| 항목 | 버전 |

| npm | 10 이상 (검증: 11.16.0) |

## 가상 시드와 데모 역할

1. `/start` → **가상 가게로 체험하기**: 카페 샘터(가상) · 음식점·카페 · 1~4명 · 직원 A·B·C. 날짜는 기준일에 맞춰 상대적으로 만들어져 언제 실행해도 위험·임박·확인 필요 항목이 보입니다.
   - 직원 A: 새 직원, 근로계약서 미교부·4대보험 아직 안 함(위험), 수습 중, 12일 뒤 시급 인상 예정(조건 이력), 직원 앱 가입함, GPS 출퇴근 기록·수정 이력·확인 대기 1건
   - 직원 B: 기존 직원(정리 완료), 유학생 D-2, 체류기간 D-4, 보건증 재검진 시기, 4대보험 노무법인에 맡김
   - 직원 C: 방금 등록한 기존 직원(한 번에 체크 전), 매주 달라요, 기간제(계약 만료 임박)
   - 가장 최근 지급일이 지난 달의 급여는 확정·교부되어 있습니다(수령 확인 시연).
2. **빈 사업장으로 시작**: 홍보 페이지 자가진단 답(업종·직원 수·외국인)을 이어받아 사업장 설정부터 시작합니다.
3. 상단 데모 안내의 **화면 둘러보기** 선택으로 사장님 / 직원 / 노무법인 / 관리자 화면을 오갑니다. **실제 인증이 아닙니다.**
   - 직원 화면은 본인 데이터만 보이도록 `src/domain/scopes.ts`의 선택자를 거칩니다(브라우저 데이터 자체는 격리되지 않음).
   - 미가입 직원은 사장님 화면 → 직원 상세 → 직원 앱·초대 → 초대 링크 만들기 → "데모: 직원으로 링크 열기"로 가입 흐름을 볼 수 있습니다.

### 기준일

모든 계산(최저임금·요율·기한·D-day)은 **기준일**로 규칙을 고릅니다. 기본은 브라우저 로컬 날짜이고, 설정 → 기준일에서 고정할 수 있습니다(예: 2027.1.1로 연도 전환 시험).

### 초기화·복원

- 설정 → 데이터: **JSON 내보내기 / 가져오기 / 데이터 초기화 / 가상 시드 복원**
- 브라우저 개발자도구에서 `localStorage`의 `ai-labor-demo/state`, `ai-labor-demo/session`을 지워도 초기화됩니다.
- 저장소를 읽을 수 없으면(사생활 보호 모드 등) 첫 화면에 오류와 [다시 시도]/[저장 데이터 초기화]가 나오고, 저장 실패 시 상단에 [다시 저장] 띠가 나옵니다.
