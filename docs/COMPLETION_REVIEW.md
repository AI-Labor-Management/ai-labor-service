# 요구사항 대조와 마감 검증

2026-11-06. 사용자 요청: 사람샘각 로고/이름의 자연스러운 물방울 반응, 전체 프론트엔드와 기본 백엔드·버그 수정, 팀원의 실제 로그인/AI API 연결을 위한 인수인계.

범위는 Notion 11.04 2차 기획안 전체다. 팀원 역할·마감일 때문에 축소하지 않는다. 최신 T06 페이지는 작업 설명만 있고 본문 요구사항이 비어 있었으며, 2인 실행 계획은 첨부 확인 전의 축소 계획이었다. 기존 계산 가정·수치가 이번 UX 작업으로 새로 검증됐다고 표시하지 않는다.

세부 기능 현황은 FEATURES, 실제 연동 계약은 API_HANDOFF를 기준으로 한다. 영어 화면은 주요 흐름의 고정 문구를 제공하며, 저장된 한국어 알림·사용자 메모·법령 근거를 실시간 번역하지 않는다. 실제 휴대폰/Safari/스크린리더와 인쇄물 전체 육안 검증은 별도다.

남은 데이터·정책: 상용 간이세액표/지방소득세 자동 계산, 공휴일 공식 대조, 학사·지역 행사 데이터, C1~C17 노무사 확인, 공식 양식 대조, 위치정보/협약/보유 기간 결정. 수동 입력·연결 대기·확인 필요 표시를 유지하며 값을 지어내지 않는다.

마감 검증: 자동 10개 파일 97개 통과, 타입 검사, 정적/서버 빌드. Chromium에서 사장님 경로 29개(탭·서류 출력·잘못된 급여 월 포함)의 렌더/NaN/가로 넘침을 점검했고, 375px 주요 경로 10개에서 문서 가로 넘침이 없었다. 개발 API 저장/새로고침 복원, 초대→조건 확인, 입력 이탈/역할 전환 취소, 손상 백업 보존/정상 백업 미리보기 취소, 검색 바깥 클릭, 로고 이름 hover/키보드 focus를 확인했다. 실제 운영 API와 SQL 검증은 포함하지 않는다.

배포/저장소 최종 위치는 HANDOFF를 참고한다.
