# 계산과 원문 해석 기록

아래는 2026-11-05 초안의 자료 해석·계산 가정입니다. 현재 서비스명은 사람샘각이며 초대·저장·UI 상태는 최신 HANDOFF를 따릅니다. 이 문서의 법령 수치는 이번 UX 작업으로 새로 검증하지 않았습니다.

## 4. 자료 충돌과 처리

| 충돌                                                                                                            | 처리                                                                                                                                  |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 11/4 2차 기획안(전체 기능) vs 11/5 "2인 개발 실행 계획"(1순위 F1~F4만, 로그인 없음, 3순위 제외)                 | 사용자 지시("담당별 일정에 의한 축소 금지")에 따라 **전체 기획 범위**로 구현. 외국인·퇴사·바쁜 시기 등 3순위도 포함                   |
| 기술: Next.js/Supabase/Vercel(독립 서비스) vs HTML 한 파일/BIX 함수(Core HR 모듈)                               | 독립형 SPA. 두 구조를 섞지 않음. HR-main 코드는 사용하지 않음                                                                         |
| rules.json의 "verified"(11.04 원문 대조 기록) vs Notion "법령·수치 대조표"(전부 미확인)                         | 두 상태를 자동으로 합치지 않음. rules.json 상태를 그대로 표시하고 규칙 화면·관리자 화면에 충돌 사실을 경고로 표시                     |
| 상담 문서 앞부분 "사장님 정보를 노무법인에 넘기지 않음" vs 뒷부분(11.03 변경) "고른 항목만, 동의 후, 철회 가능" | 나중 기록(변경 후)을 따름                                                                                                             |
| F1 07 10장 "직원 앱에서 냈어요" vs 15번(11.03) "사장님이 문구 복사 → 실물 확인"                                 | 15번을 따름. 직원 앱에 서류 기능 없음                                                                                                 |
| 1~4명 연장 한도(7번)·괴롭힘(9번): 팀원 의견(적용) vs 시행령 별표 1(미적용)                                      | 기획안대로 "법적 의무 아님·권장" + 근거에 양쪽 표시                                                                                   |
| 주 14시간 직원의 건강·연금: 손계산 예제 #5(제외 예상) vs 월 환산(60.8시간 ≥ 60)                                 | 예제를 따라 **주 15시간 미만이면 제외 예상**으로 두고, 화면에 "월 60시간 경계 근처, 실제 계약 기준 확인" 문구를 붙임 (`insurance.ts`) |
| 홍보 페이지 설문 수치                                                                                           | 기획 결정대로 공개 페이지에 수치를 쓰지 않음                                                                                          |
| 서비스 이름                                                                                                     | 사용자 지정 이름 '사람샘각' (`src/ui/brand.ts`)                                                                                       |

## 5. 해석·가정으로 정한 계산 규칙 (노무사 확인 대상)

| 규칙              | 구현                                                                                                                          | 위치                      |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| 주휴 귀속         | 월~일 주, **일요일이 속한 기간**에 귀속                                                                                       | `wage.ts`                 |
| 입사한 주 주휴    | 근무한 날 기준 비례 + "확인 필요" 플래그. 4주 평균은 계약 주 소정시간 기준                                                    | `wage.ts`                 |
| 퇴사 주 주휴 (C2) | 계산은 보여주되 **지급액에 자동 포함하지 않음**                                                                               | `wage.ts`                 |
| 대타 주 주휴 (C3) | 근무일 변경으로 보아 지급, "확인 필요"                                                                                        | `wage.ts`                 |
| 연장 계산         | 1일 8h 초과 + (주 40h 초과 − 1일 초과분), 휴일근로는 연장에서 제외, 주 연장은 일요일 귀속                                     | `wage.ts` `premiumsFor`   |
| 야간              | 22~06시 겹침 전체 (휴게 시각을 받지 않아 야간에서 빼지 않음)                                                                  | `dates.ts`                |
| 단시간 초과 가산  | 일별 소정 초과분 − 주 연장분 (근사)                                                                                           | `wage.ts`                 |
| 5명 이상 공휴일   | 계약 근무일이 공휴일이면 유급휴일로 일정에서 빼고 소정시간만큼 지급, 근무 넣으면 휴일 가산                                    | `work.ts`, `wage.ts`      |
| 출퇴근 반영       | 허용 오차(기본 5분) 안이면 예정 시간. 일찍/늦게는 승인("기록 시간대로") 전에는 더하지 않음. 지각·조퇴는 일하지 않은 시간만 뺌 | `work.ts` `workedSegment` |
| 월 환산 시간      | (주 소정 + 주휴) × 365/7/12 반올림 (40h → 209h)                                                                               | `hours.ts`                |
| 보험료 끝수       | 국민연금 기준소득월액 천 원 미만 버림, 모든 보험료 10원 미만 절사 ("예상")                                                    | `insurance.ts`            |
| 4대보험 상실일    | 퇴사일 다음 날                                                                                                                | `insurance.ts`            |
| 퇴직금 3개월 임금 | 확정 급여 스냅샷이 아니라 근무 기록·일정으로 다시 계산한 지급액                                                               | `severance.ts`            |
| 연차              | 출근율 80% 이상 가정, 1년 미만은 결근 기록 있는 달 제외, 현재 연차 기간만 표시                                                | `leave.ts`                |
