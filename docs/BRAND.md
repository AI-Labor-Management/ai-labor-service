# 사람샘각

서비스명은 2026-11-06 사용자가 직접 지정한 **사람샘각**이다. Notion에 남아 있는 '서비스 이름 미확정' 기록과 초기 'AI 인사노무 관리' 가칭보다 이번 지정이 우선한다. 설명 문구는 '소상공인을 위한 인사·노무 관리'다.

심볼은 사용자가 요청한 **샘물**이다. 안쪽에 흐름을 비운 물방울과 아래로 퍼지는 두 겹의 물결로 구성한다. 짙은 남색의 물방울, 차분한 물빛의 바깥 물결로 색을 제한한다. 이번 프로젝트에서 직접 작성한 SVG이며 외부 서비스 로고를 가져오지 않았다. 상표 등록 여부를 확인했다는 뜻은 아니다.

- 이름과 설명의 기준: `src/ui/brand.ts`
- 화면 로고: `src/ui/Icon.tsx`의 `Brand`
- 사용자 후속 요청으로 로고 아래 '인사노무 관리' 설명은 표시하지 않는다. 이름과 심볼만 사용하며, 검색용 설명 문구와 브라우저 제목은 별도다.
- 단독 심볼 / 파비콘: `public/brand-symbol.svg`
- 단색 심볼: `public/brand-symbol-mono.svg`. 인쇄나 단색 사용 시 활용한다.
- 기본 글자: Pretendard와 한국어 시스템 대체 글꼴
- 색: 흰색과 중성 차콜. 짙은 슬레이트 블루는 주요 동작·선택·심볼에 제한한다.
- 세 SVG path와 48×48 viewBox는 화면 로고·단독·단색 심볼 사이에 동일하게 유지한다. 바깥 물결의 색은 `--logo-water` 토큰이다. 배경 효과·그라데이션·입체 그림자를 더하지 않는다.
- `compact`는 워드마크를 숨기는 용도이며 심볼을 다른 모양으로 바꾸지 않는다.

Sites의 표시 이름도 사람샘각으로 통일한다. 기존 URL과 프로젝트 ID를 유지해 공유 링크가 끊기지 않게 한다. GitHub 저장소 이름은 `ai-labor-service`를 유지한다.
