# UI 설계와 수정 기준

## 방향

**사람샘각**은 소상공인 사업주가 직원·근무·급여·서류·기한을 관리하는 업무 도구다. 2026-11-06 사용자가 정한 서비스명을 기준으로 삼으며 `docs/BRAND.md`를 따른다. 장식보다 정보의 비교와 다음 행동이 분명하도록 만든다.

특정 금융 앱의 파란색, 과장된 잔액 카드, 기울어진 대시보드와 떠다니는 배지를 한 세트로 재현하지 않는다. 기존에 만든 검색·메뉴·테마·사용 안내의 편의성은 유지한다.

## 시각적 기준

- 색상: 흰색·중성 차콜을 기본 바탕으로 사용한다. 짙은 슬레이트 블루는 주요 행동·선택·심볼에 한정한다. 넓은 면에 연두색을 쓰지 않는다. 위험·경고는 각각의 의미 색과 문구를 함께 쓴다.
- 심볼: 두 개의 열린 곡선이 이어지는 자체 SVG. 화면의 Brand와 public/brand-symbol.svg는 같은 path를 사용한다.
- 글자: 일반적인 한국어 시스템 글꼴과 Pretendard 대체 체계. 제목의 과도한 자간 축소와 큰 숫자 강조를 줄인다.
- 요약 영역: 개별 금융 카드 대신 구분선이 있는 업무 현황표. 예상 인건비는 '지급액 기준'과 사업주 보험 부담을 함께 표시한다.
- 공개 첫 화면: 가상 카페의 업무 흐름 예시. 예시 수치나 상태를 실제 고객 실적으로 표현하지 않는다.
- 애니메이션: 모달 열기/닫기와 메뉴·가이드의 상태 변화를 설명한다. 업무 화면의 장식적 등장 애니메이션은 사용하지 않는다. 동작 줄이기를 존중한다.

## 수정할 파일

| 수정 대상                          | 파일                                                            |
| ---------------------------------- | --------------------------------------------------------------- |
| 밝은/어두운 색상·행동 색·모서리 값 | `src/styles/tokens.css`                                         |
| 배치·반응형·애니메이션             | `src/index.css` 다음 `src/styles/refinement.css`                |
| 브랜드명·심볼·파비콘               | `src/ui/brand.ts`, `src/ui/Icon.tsx`, `public/brand-symbol.svg` |
| 공통 버튼·카드·입력·대화상자       | `src/ui/kit.tsx`, `src/ui/useDialog.ts`                         |
| 공개 헤더                          | `src/ui/SiteHeader.tsx`                                         |
| 메뉴 정의                          | `src/ui/navigation.ts`                                          |
| 역할별 틀·메뉴 위치·모바일 메뉴    | `src/ui/layouts.tsx`                                            |
| 검색·테마 저장·애니메이션 안내     | `src/ui/Search.tsx`, `preferences.tsx`, `Guide.tsx`             |
| 홍보·가입 시연·사장님 홈           | `src/pages/public/`, `src/pages/owner/Home.tsx`                 |

새 화면에서도 색상 값을 직접 넣기보다 `brand`, `canvas`, `line`, `--action` 같은 토큰을 사용한다. 카카오처럼 제공사가 정한 색상은 별도로 유지한다. 계산과 판정은 `src/domain`을 호출하고 UI 안에서 다시 만들지 않는다.

## 상호작용과 데이터

- 상단 검색은 메뉴와 직원 별칭을 찾는다. 직원 역할에서는 다른 직원 데이터가 결과에 나타나지 않아야 한다.
- 메뉴는 데스크톱에서 접기·펼치기와 좌우 배치, 모바일에서 모달 서랍을 지원한다. 상태는 `ai-labor-ui/sidebar`, `ai-labor-ui/sidebar-side`에 저장한다.
- 테마는 `ai-labor-ui/theme`에 저장한다. 업무 데이터와 분리되어 있으며 기존 `schemaVersion: 1`을 변경하지 않는다.
- 로그인·회원가입은 입력 검증을 보여주는 임시 폼이다. 비밀번호·이메일을 저장·전송하거나 실제 계정 생성으로 표시하면 안 된다.
- 안내 장면은 실제 업무를 대신 수행하지 않는 가상 예시다. 재생·정지·단계 선택·닫기가 가능하다.

## 확인 절차

1. `npm test`, `npm run build`.
2. 홍보 → 가입 시연(잘못된 입력/정상 입력) → 가상 가게 또는 이어서 관리.
3. 검색에서 직원 별칭을 입력하고 Enter로 상세 화면 이동.
4. 메뉴 접기·좌우 배치·새로고침 복원·모바일 메뉴 열기/닫기.
5. 밝은 모드와 어두운 모드, 가입/급여/서류 화면의 글자 대비.
6. 가이드 재생·정지·단계 이동, 동작 줄이기 설정.
7. 1440px와 375px에서 문서 전체의 가로 넘침 여부. 넓은 표는 표 영역 안에서 스크롤되어야 한다.

모달은 바깥에서 누르고 바깥에서 놓았을 때만 닫는다. 안에서 시작한 드래그로 닫히면 안 된다. 배경 스크롤 잠금과 native 포커스 복귀를 유지한다. 검색은 입력부와 결과 스크롤을 분리한다. 공통 탭의 방향키 이동과 홈 필터의 URL 복원도 유지한다. 자세한 확인 기록은 [UX_REVIEW](UX_REVIEW.md).

포맷 설정은 `.prettierrc.json`에 있다. UI 파일을 바꾼 뒤 필요하면 `npx prettier@3.6.2 --write <수정한 파일>`로 정리한다. 기존 계산 파일 전체를 일괄 포맷할 필요는 없다.
